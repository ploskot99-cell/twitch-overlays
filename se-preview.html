Test events — ίδια ονόματα με του StreamElements
Επικόλληση στο StreamElements
Overlay editor → + Add Widget → Static/Custom → Custom Widget Settings → OPEN EDITOR, και σβήσε ό,τι έχει μέσα Πάτα ένα κουμπί, πήγαινε στην ομώνυμη καρτέλα του SE, Ctrl+V. Και τα τέσσερα. Done → μεγάλωσε το widget στον καμβά
Φορτώνει τα widget.html, widget.css, widget.js και fields.json από το dist/<client>-se/<widget>/, τα ενώνει σε ένα iframe και στέλνει onWidgetLoad και onEventReceived ακριβώς όπως το StreamElements. Αν παίζει εδώ, παίζει και εκεί.

Φτιάξε πρώτα τα αρχεία με node make-se.js <client>.
