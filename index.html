Πώς μπαίνει στο OBS

  1. Στο OBS: Sources → + → Browser.
  2. Κάνε Αντιγραφή εδώ πάνω και επικόλλησε στο πεδίο URL. (Εναλλακτικά τσέκαρε Local file και διάλεξε το αρχείο.)
  3. Βάλε το Width / Height που γράφει το «Προτεινόμενο μέγεθος».
  4. Τσέκαρε Shutdown source when not visible και Refresh browser when scene becomes active — έτσι τα alerts ξεκινούν καθαρά κάθε φορά.
  5. Για πραγματικά events άνοιξε το js/config.js και βάλε το κανάλι σου και τα sources. Οδηγίες στο README.md.
